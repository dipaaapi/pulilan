# Barangay Monitoring System (CBMS) for the Provincial Municipality of Pulilan, Bulacan

## 📋 System Overview
The **Barangay Monitoring System (CBMS)** is an integrated, web-based platform engineered to streamline local governance, resident data management, and inter-agency communication for the Provincial Municipality of Pulilan, Bulacan. Designed to replace fragmented record-keeping, the system bridges local barangays, municipal administrators, and national agencies (such as the DILG) by offering centralized user administration, automated barangay profiling, demographic and household surveys, integrated messaging, and secure access-controlled dashboards for different municipal roles.

---

## 🛠️ Tech Stack & Architecture
* **Backend:** PHP (Native/Procedural & Object-Oriented modules)
* **Database & Management:** MySQL (Relational database managed via Laragon / HeidiSQL)
* **Frontend Framework:** Bootstrap (v3/v4 UI components) & HTML5 / CSS3
* **Scripting & Interactivity:** JavaScript, jQuery, and MetisMenu
* **Server Environment:** PHP Development Server / Apache (via Laragon)

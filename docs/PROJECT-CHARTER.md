# Project Citizen's Charter

The public guide is available at `index.php?page=citizen-charter` with a native
browser PDF frame and direct open/download links. The homepage resource section
links to it. The PDF is `public/documents/project/citizen-charter.pdf`.

Seven pages cover account registration and activation, resident surveys,
information and reporting, inquiries, staff roles, privacy, accessibility, and
feedback. Service tables identify client steps, system/staff actions, fees,
processing-time guidance, and responsible people.

The municipal reference is the Municipal Information and Communications
Technology Office (MICTO), identified in the official office directory. This
project has not been assigned to that office or approved as a municipal service.
The document is labelled a project draft throughout; manual approval and reply
deadlines are not invented. User-effort estimates are not official service-level
commitments. The guide reflects local inbox handling and current application
permissions, not automated government email delivery or permit processing.

To regenerate, install ReportLab in the maintenance Python environment and run
`python tools/build-citizen-charter.py`. ReportLab is not a PHP runtime dependency.
Render and review every page after changes. Reviewed sources and their URLs
are printed on the last page. Version 1.0 was prepared October 13, 2026.

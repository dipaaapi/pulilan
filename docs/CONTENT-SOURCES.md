# Official municipal content

Reviewed on October 13, 2026. This is a curated snapshot, not a live feed.
Edit `app/content/municipality.php` to maintain the shared content. The home page
renders it through `views/components/municipal-information.php`.

| Source | Use |
| --- | --- |
| [History](https://pulilan.gov.ph/about-pulilan/history/) | Town declaration date, patron saint, name origin; summarized |
| [Vision and mission](https://pulilan.gov.ph/government/vision-mission/) | English summary of the published Filipino vision and all ten mission priorities |
| [Office directory](https://pulilan.gov.ph/government/office-directories/) | Mayor's office, planning office, and disaster management contacts |
| [Contact page](https://pulilan.gov.ph/contact-us/) | Cross-check of the mayor's office phone and general email |
| [Citizen's Charter](https://pulilan.gov.ph/citizens-charter/) | Direct resource link for official service information |
| [Demographic profile](https://pulilan.gov.ph/about-pulilan/demographic-profile/) | Reference link only; confirms nineteen listed barangays |

The published vision differs from the previous project text. Its summary now
follows the official page. Mission priorities include gender-responsive
governance, which was missing from the previous home page.

The demographic page combines an undated population table with employment data
labelled 2006 and income and birth data labelled 2022. These are not presented as
current population or imported into operational survey tables. Existing database
profiles, spellings, identifiers, and survey records remain unchanged.

The homepage hotline panel and office directory list different phone numbers
for some offices, including the fire station and police. The project uses the
three selected directory entries and links visitors to the full official
directory. Recheck contact information before updating this snapshot.

News, vacancies, and elected officials change frequently and remain on the
official site. Selected official documents, the municipal logo, and site icon
were subsequently copied; see [the asset register](OFFICIAL-ASSETS.md).
No official-site forms were submitted or third-party scripts copied. Project inbox submissions are local and do
not send messages to municipal email addresses.
